## Что изменилось после ТЗ

Датасет заказчика показал: слабый сигнал в его понимании — это **раунды,
выходы из stealth, первые внедрения**, и живёт он в отраслевых медиа, а не в
научных статьях. Из 206 доменов-источников arXiv — 18, TechCrunch — 11.
OpenAlex не видит «три стартапа вышли из stealth». Поэтому:

- корпус из 6 млн статей **больше не критический путь**. Докачать можно, но
  кластеризация 6 млн — снята. Публикации нужны для года взлёта и географии,
  и для этого хватает точечных запросов по кандидатам;
- главная работа — **новостной слой** и **живой сбор по произвольному запросу**.
  Жюри вводит направление, которого нет в индексе, и ждёт минуты, не часы.

**Твои папки: `ingest/`, `semantic/`.** Плюс новая `ingest/live/`.

## Что ты отдаёшь наружу

Контракт `WORKS` расширен (см. `contracts/schemas.py`): добавились
`source_type`, `trust_level`, `summary_ru`, `summary_model`. Заполняешь
`source_type` и `trust_level`; резюме — не твоё.

Новый выход: **живой корпус по запросу** — `data/live/{slug}/works.parquet`
и `meta.json` со счётчиками `n_sources_polled`, `n_docs`, `elapsed_s`.

## Задачи, по порядку

### K-10. Справочник доверенности источников (день 1)
`ingest/trust.py`: домен → `trust_level` и `source_type` по правилам ТЗ.
- **trusted**: госорганы, регуляторы, университеты, научные центры, компании-
  разработчики, отраслевые ассоциации, журналы, конференции, патенты, реестры,
  профессиональные отраслевые медиа, аналитические отчёты;
- **indicator**: соцсети, личные блоги, агрегаторы, анонимные ресурсы, реклама,
  пресс-релизы — только первичный индикатор, не основание для включения;
- **unknown**: всё остальное.
Начни с 206 доменов из датасета (`../tz/Датасет/…xlsx`, колонка «Источники»)
и наших: arxiv, openalex, nature, github, huggingface — trusted; prnewswire,
medium, x.com, reddit — indicator. Тест: у каждого домена из датасета есть уровень.

### K-11. Новостные коннекторы без ключей (дни 1–3)
`ingest/sources/`:
- `rss.py` — TechCrunch, SiliconANGLE, VentureBeat, The Register, EE Times:
  публичные RSS, парсить `feedparser`. Дата, заголовок, ссылка, язык `en`.
- `hackernews.py` — `https://hn.algolia.com/api/v1/search?query=…` — без ключа,
  есть дата и очки; тип `indicator`, `source_type=aggregator`.
- `gnews.py` — Google News RSS: `https://news.google.com/rss/search?q=…&hl=en`
  и `hl=ru` для русскоязычных. Тип по домену через `trust.py`.
- `github.py` и `huggingface.py` — уже есть, добавь дату создания и звёзды.
Каждый коннектор: кэш на диск, ретраи, `from_*()` в `normalize.py` → `WORKS`.
`doc_id` = `"{source}:{sha1(url)[:16]}"`.

### K-12. Живой сбор по запросу (дни 3–6) — главная задача
`python -m ingest.live --query "перспективные решения в финтехе" --budget 180`
1. Запрос на русском → английские ключевые фразы. Через LLM (наш `cards/llm.py`
   уже умеет, импортируй) с явным логом: модель, промпт, ответ — в `meta.json`.
2. Параллельный опрос всех коннекторов с общим бюджетом времени, обрыв по таймауту
   без падения — что собрали, то собрали. `asyncio` + `httpx.AsyncClient`.
3. Дедуп по URL и по нормализованному заголовку.
4. OpenAlex — **точечно**: только по 30–50 самым частым фразам из собранных
   заголовков, `group_by=publication_year`, чтобы дать году взлёта историю.
5. Выход: `data/live/{slug}/works.parquet` по контракту + `meta.json`.
Критерий: запрос «слабые сигналы в области кибербезопасности» даёт ≥300
документов за ≤3 минуты на M1 Pro без GPU.

### K-13. Кандидаты из живого корпуса (дни 6–8)
`semantic/build.py --scope live` — только термины и **сущности**: названия
компаний и продуктов из заголовков (NER через `spaCy en_core_web_sm` или
регулярки по капитализации — что быстрее). Эмбеддинги и кластеры для живого
режима **выключены**: нет времени и GPU на ноутбуке жюри. Порог — от 3 документов.
Техно-фильтр `filter.py` обязателен: `covid-19 pandemic` до сих пор в выдаче.

### K-14. Новостные признаки для классификатора (дни 8–10)
Антону для этапа 1 нужны по каждому кандидату: число упоминаний по месяцам за
24 месяца, число разных доменов, число `trusted` источников, число компаний,
упоминания слов `funding|raises|series|seed|stealth|pilot` в заголовках.
Функция `ingest.features.news_features(cand_docs, works) -> dict[cand_id, dict]`.
Контракт согласуй с Антоном до кода — он владелец схем.

### K-15. Датасет заказчика как корпус (дни 10–12)
100 технологий из xlsx: перевести названия в английские запросы (LLM, лог),
прогнать через `ingest.live` каждую, сложить в `data/dataset/`. Это обучающая
выборка для классификатора — без неё этап 1 не сдаётся. Кэшировать всё:
прогон повторяться не должен.

## Чего не делать
Не считать скоринг, не трогать `core/`, не кластеризовать 6 млн, не ставить
Postgres — это Антон. Не ослаблять техно-фильтр ради «больше кандидатов».

и твои PR мержатся вслепую. `git fetch && git rebase origin/main` перед PR.
