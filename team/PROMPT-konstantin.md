```

  http.py         кэш + ретраи + rate limit (перенести из спайка)
  sources/
    openalex.py   основной источник
    arxiv.py
    crossref.py
```

Требования:

- всё кэшируется на диск, повторный прогон бесплатный;
- CLI умеет докачивать: повторный запуск не начинает с нуля.

### K-04. Эмбеддинги (день 3)
```python
from sentence_transformers import SentenceTransformer
m = SentenceTransformer("intfloat/multilingual-e5-large", device="cuda")
# e5 требует префиксы: документы кодируем как "passage: ...", запросы как "query: ..."
emb = m.encode(["passage: " + t for t in texts],
               batch_size=64, normalize_embeddings=True,
               convert_to_numpy=True, show_progress_bar=True)
```
Кодируем `title + ". " + abstract`, обрезая до 512 токенов. Сохраняем
`float32`, L2-нормированные. На 3070 (8 ГБ VRAM) batch 64 влезает; если поймаешь
OOM — уменьшай batch, не модель.

Замерь и запиши в `meta.json`, сколько документов в секунду. От этого зависит,
сколько доменов мы успеем проиндексировать.

### K-05. Кластеризация (дни 4–5)
Рецепт, отклоняться без причины не надо:

```python
import umap, hdbscan
red = umap.UMAP(n_neighbors=15, n_components=5, min_dist=0.0,
                metric="cosine", random_state=42).fit_transform(emb)
lab = hdbscan.HDBSCAN(min_cluster_size=25, min_samples=5,
                      metric="euclidean",
                      cluster_selection_method="eom").fit_predict(red)
```
- `random_state=42` обязателен: без него прогоны невоспроизводимы, а
  воспроизводимость — часть нашего питча.
- `-1` в `lab` означает шум, это нормально, такие документы не попадают в кластеры.
- Названия кластеров — через **c-TF-IDF** (по формуле из BERTopic): считаешь TF-IDF,
  где «документ» — это склейка всех текстов кластера. Топ-10 слов → `top_terms`,
  первые 3–4 → `label`.

Крутилка, которую надо подобрать: `min_cluster_size`. Слишком большой — слабые
сигналы сольются с мейнстримом; слишком маленький — тысячи мусорных кластеров.
Начни с 25, попробуй 10 / 25 / 50 и покажи Антону, что получается.
