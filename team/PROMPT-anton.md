### A-02. Перенести скоринг из спайка в `core/` (дни 1–2)
```
core/
  series.py       годовые ряды кандидатов (DuckDB-джойн cand_docs × works)
  normalize.py    peer-нормировка
  components.py   N, G, A, B, D + зрелость
  filters.py      структурные фильтры
  dedup.py        схлопывание вариантов + MMR по эмбеддингам
  score.py        Emergence Score, сборка trends.parquet
  cli.py          python -m core.build --domain ... --as-of 2026
```
Логика есть в `spikes/openalex_probe.py`, но там она считает всё сама через HTTP.
Теперь вход — parquet от Константина, выход — `trends.parquet`. И покрой тестами:
скоринг — единственное место, где тихая ошибка не видна глазом.

**Два бага из прототипа, которые надо починить по дороге:**
- дедуп не схлопывает единственное/множественное число: `generative adversarial
  network` и `...networks` заняли два места из пятнадцати. Жаккар по токенам даёт
  0.5 при пороге 0.6. Нужна лемматизация.
- `data/results/run_ai_2026.txt` оборван на пятой строке (прогон убили по памяти) —
  перегенерировать, это артефакт для питча.

### A-03. Генерация кандидатов v2 — главная задача недели (дни 2–4)
Это то, что отделяет нас от «среднего решения». Сейчас система находит
`explainable machine learning` и `fraud detection` — мейнстрим и прикладные
применения, а не зарождающиеся технологии.

Четыре рычага, работать со всеми:
1. полный корпус вместо `sample` (это делает Константин, K-03);
2. опережающие источники: препринты дают фору в 1 год (измерено), HuggingFace ещё раньше;
3. кластеры вместо строк — у зарождающегося тренда часто ещё нет устоявшегося
   названия, это следует из определения;
4. техно-фильтр сущностей (K-07).

Критерий готовности: на срезе 2021 в ТОП-15 попадают `transformer`,
`self-supervised learning`, `diffusion model` — то, что метод обязан был найти
и не нашёл. Это твой личный тест.

### A-04. Разрешение омонимии (день 5)
Измерено: `diffusion model` в журналах взлетает в 2005 (физика диффузии),
`state space model` — в 2005 (теория управления). Год взлёта считается неверно,
и тренд отбраковывается фильтром возраста как «старый».
Решение: привязка к кластеру/эмбеддингу контекста, а не к строке.

### A-05. Бэктест как функция продукта (день 6)
`--as-of 2021` должен работать сквозь весь конвейер, а не быть отдельным скриптом.
Это номер, который решает питч: на глазах жюри выставляем 2021 и показываем,
что сервис нашёл бы тогда и что из этого выросло.

### A-06. Отчёт валидации (день 7)
```
validation/
  reference.py    эталонный список технологий, выстреливших в 2022-2026
  metrics.py      Precision@15, lead time, recall по эталону
  baselines.py    топ по абсолютному приросту / по CAGR / голая LLM
  ablation.py     отключаем компоненты по одной, смотрим падение
  report.py       -> validation/REPORT.md + JSON для /api/v1/methodology
```
Эталонный список (transformer, diffusion models, LLM, RAG, Mamba/SSM, LoRA,
vector DB, vision-language models, ...) собери **до** прогонов, чтобы не было
соблазна подогнать. Это вопрос честности метода, и жюри такое считывает.
