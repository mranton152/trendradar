# Архитектура

## 1. Главное архитектурное решение: гибрид предрасчёта и онлайна

Жюри вводит «квантовые вычисления» и ждёт результат. Честный полный обход
источников — это минуты, а то и десятки минут. Ждать никто не будет.

Поэтому два контура:

```
┌─ ОФЛАЙН (заранее, по расписанию) ──────────────────────────┐
│  сбор корпуса → эмбеддинги → кластеры → метрики → индекс   │
│  по 10-15 крупным техно-доменам                            │
└────────────────────────────────────────────────────────────┘
                          │
                    предрассчитанный индекс
                          │
┌─ ОНЛАЙН (запрос пользователя, < 3 сек) ────────────────────┐
│  нормализация домена → поиск по индексу → ранжирование →   │
│  сборка карточек → выдача                                  │
│                                                            │
│  если домена нет в индексе:                                │
│    быстрый ответ по ближайшим темам + фоновая доиндексация │
│    с прогрессом ("уточняем по свежим источникам...")       │
└────────────────────────────────────────────────────────────┘
```

Это одновременно и техническое решение, и страховка демо.

## 3. Контракт API (черновик до ТЗ)

```
POST /api/v1/trends
{
  "domain": "технологии в ИИ",
  "top_n": 15,
  "horizon_years": 5,
  "sources": ["openalex", "arxiv", "patents"],
  "as_of": 2026          // срез времени: включает режим бэктеста
}

200 OK
{
  "domain": {"query": "...", "resolved": "Artificial intelligence", "docs": 34551637},
  "methodology": {"weights": {...}, "filters": {...}, "version": "1.0"},
  "trends": [{
    "rank": 1,
    "title": "Физически-информированные нейронные сети",
    "aliases": ["physics-informed neural networks", "PINN"],
    "emergence_score": 0.803,
    "components": {"novelty": 0.9, "growth": 0.82, "accel": 0.75,
                   "burst": 0.6, "diffusion": 0.71},
    "evidence": {
      "first_mention": 2019, "takeoff_year": 2022,
      "publications": {"2022": 340, "2023": 780, ...},
      "countries": 96, "organizations": 412, "patents": 37
    },
    "motivation": {"problem": "...", "advantage": "...",
                   "sources": ["W123", "W456"]},
    "case_example": {"type": "company", "name": "...",
                     "description": "...", "source": "..."},
    "sources": [{"title": "...", "url": "...", "year": 2024, "type": "article"}],
    "confidence": "high",
    "stage": "early_growth"

```

`as_of` в API — не украшение: он делает бэктест не отдельным скриптом, а
**функцией продукта**. На защите можно вживую выставить 2021 год и показать,
что сервис нашёл то, что потом выстрелило.

## 4. Развёртывание

Всё в Docker Compose, одна команда на подъём — жюри часто просит развернуть у себя.

```
postgres (+pgvector) · redis · api · worker · frontend · [ollama]
```

**Важное ограничение macOS:** Metal/GPU не пробрасывается в контейнеры Docker на
macOS. Поэтому:

- в контейнерах — инфраструктура и приложение;
- эмбеддинги и LLM — нативным процессом на хосте (Ollama/MLX), контейнеры ходят
  в него через `host.docker.internal`;
- в манифестах предусмотреть оба режима: `LLM_BACKEND=ollama_host | vllm_container | api`.

Иначе весь ML на M4 Pro будет считаться на CPU внутри виртуалки — на порядок медленнее.
