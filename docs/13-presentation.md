## 11. Коротко о решении (шаблон)

**Техническая суть.** Конвейер из стадий, каждая пишет parquet: сбор →
кандидаты → скоринг → карточки → API → интерфейс. Классификатор на
интерпретируемых признаках отделяет зарождающееся от зрелого. Индекс — это
файлы, поэтому демо работает без сети.

**Суть для бизнеса.** Банк узнаёт о технологии на годы раньше рынка.
Медианная фора обнаружения до пика — **6 лет** ✅.

## 12. Проблема и что такое слабый сигнал

Знание о технологии приходит в банк, когда вкладываться поздно.

Одна кривая: зарождение → рост → мейнстрим. Две отметки: где узнаёт рынок
и где видно в данных. Между ними и живёт слабый сигнал.

**Чем это трудно.** Слабый сигнал — 10–100 работ в год на домен из миллионов.
Отбор по частоте находит мейнстрим по построению. Наш собственный ранний
прогон это показал: ТОП занимали `explainable machine learning` и
`risk stratification` ✅ (`data/results/run_ai_2026.json`).

## 13. Методология: как система понимает, что это сигнал

**Два механизма, и оба объяснимы.**

Скоринг — пять компонент, каждая считается по динамике и показывается в
интерфейсе: новизна (год выхода на 10% своего пика), рост, ускорение,
всплеск, распространение по странам. Плюс штраф за зрелость: высокая
абсолютная частота — минус, а не плюс.

Классификатор — обучен на датасете заказчика, 13 признаков, у каждого
человеческая формулировка. Модель показывает вклад каждого ✅.

Опора — рамка Rotolo, Hicks & Martin (2015) «What is an emerging technology?».

## 14. Классификатор: этап 1

Среднее по 20 случайным разбиениям 5-fold кросс-валидации:

| Модель | Accuracy | Диапазон | Precision | Recall | F1 |
|---|---|---|---|---|---|
| логистическая регрессия | 71% | 67–73% | 0.71 | 0.72 | 0.71 |
| градиентный бустинг | 76% | 71–78% | 0.75 | 0.80 | 0.77 |
| случайный лес | 77% | 75–79% | 0.75 | 0.83 | 0.79 |
| **лес + смысл запроса (e5)** | **78%** | **76,5–80%** | **0.76** | **0.83** | **0.80** |

Порог ТЗ 75% лес + e5 берёт **на всех 20 разбиениях**.
Голосование леса и логистической регрессии на векторе `multilingual-e5-large`
английского запроса (`classifier/embed.py`) даёт +1,2 п.п. к лесу. Кодируется
только запрос, не название технологии: по одной длине и скобкам названия
класс угадывается на 97% — это была бы утечка стиля разметки, а не новизна.

✅ `classifier/REPORT.md`. Выборка: 100 положительных заказчика + **96 зрелых
технологий, размеченных нами** по критерию ТЗ, поровну по шести областям.

Сильнейшие предикторы: число репозиториев на GitHub, звёзды, доля свежих
репозиториев, всплеск и рост публикаций.

**Что говорим про порог прямо.** ТЗ: «не ниже 80%, возможно 75%».
Нижний взят, верхний — нет. Мы не подкручиваем: три модели сравнивались на
одной кросс-валидации, и об этом сказано в отчёте.

## 16. Продукт

Три экрана: запрос → ТОП-15 с уверенностью в процентах → карточка-отчёт.

Для каждого источника — наименование, ссылка, дата, тип, язык и **уровень
доверенности**; для зарубежных — русское резюме с пометкой, какой моделью
сгенерировано. Счётчики в шапке: обработано источников, найдено кандидатов,
сигналов с уверенностью выше 75%.

**Отдельно показываем исключённых** с причинами — этого не делает никто.

⬜ живой запрос по произвольному направлению с прогрессом сбора.

## 17. Честность: где метод слеп

**Мы дважды получали красивую цифру на сломанных данных и оба раза поймали себя.**

Первый раз: OpenAlex отбил 441 запрос из 1176 по лимиту, а код записал отказы
как «ноль публикаций». Модель училась на дырах. Отчёт удалили, не коммитили.

Второй раз: искали точную фразу в кавычках — «AI agent IAM» дословно ноль
работ, без кавычек 136. Нулей было у 63 сигналов из 100.

**Что метод не умеет сейчас.** Почти все ошибки — «сигнал принят за зрелое»:
нейроморфные чипы, event-based сенсоры, аналоговые compute-in-memory. У них
наука старая, а коммерческий сигнал новый, и публикационные признаки этого
не различают по построению.

**Отрицательный результат, который мы не спрятали.** Добавили новостные
признаки — стало хуже, 76% → 74%: поиск по фразе меряет известность названия,
а не новизну. Убрали и записали почему.

**Омонимия.** `diffusion model` до 2020 — физика диффузии; без разделения
год взлёта уезжает на двадцать лет назад ✅ (2002 → 2023).

## 18. Архитектура и стек

Конвейер стадий, пишущих parquet; read-only API поверх файлов; PostgreSQL
для сырых данных и результатов; всё в Docker.

Python 3.12 · scikit-learn · DuckDB + Parquet · FastAPI · Next.js ·
локальная модель через Ollama, провайдер меняется конфигом.

**Ни одной внешней зависимости, требующей учётной записи**: семь источников
работают без ключей ✅. Для закрытого контура банка это аргумент.

## 19. Ценность для банка и развитие

Раньше конкурентов увидеть точку роста → выбрать инвестиционную стратегию.

Работает в закрытом контуре: всё open-source, LLM меняется конфигом на
GigaChat или YandexGPT, демо работает без сети по построению.
Встраивается в Платформу ИИ-аналитики: REST API — первичный контракт.
Доменно-независимо: методология не знает, что такое ИИ.

Развитие: новостной слой для сигналов, живущих только в индустрии;
патентный коннектор в контуре банка, где есть корпоративные учётные записи.
