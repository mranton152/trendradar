# Источники данных

Все статусы ниже — **реально проверены** запросами с сервера 07.09.2026,
не взяты из документации.

## 1. Научные публикации

| Источник | Статус | Ключ | Заметки |
|---|---|---|---|
| **OpenAlex** | 200 ✅ | не нужен (polite pool по email) | Основной источник. 34,5 млн работ только по концепту «AI». CC0. Есть `sample`+`seed` (воспроизводимые выборки), `group_by` (годовая гистограмма одним запросом), `select` (урезание ответа). Доступен полный снапшот на S3 |
| **arXiv API** | 200 ✅ | не нужен | Только `https` (`http` отдаёт 301). Опережающий источник: медианная фора 1 год перед журналами |
| **Crossref** | 200 ✅ | не нужен | Метаданные DOI, дополняет OpenAlex |
| **bioRxiv/medRxiv** | 200 ✅ | не нужен | Препринты по биотеху |
| **OpenAIRE** | 200 ✅ | не нужен | Европейские публикации + связь с грантами |
| **Semantic Scholar** | 429 ⚠️ | **нужен** | Без ключа режет сразу. Ценен полем `tldr` и графом цитирований. Ключ запрашивается бесплатно, но выдают до недели — **заказать заранее** |
| **CORE** | 429 ⚠️ | **нужен** | Полные тексты. Бесплатный ключ |

## 2. Патенты — сигнал коммерциализации

Патент означает, что технологию собираются применять. Лаг «первая публикация →
первый патент» — наша метрика трансляции в практику (**T**).

| Источник | Статус | Ключ | Заметки |
|---|---|---|---|
| **PatentsView (US)** | нет соединения ❌ | **нужен** | Домен `search.patentsview.org` требует ключ; регистрация бесплатная |
| **EPO OPS** | 403 ⚠️ | **нужен** | OAuth, бесплатная квота ~4 ГБ/мес. Европа + WIPO |
| **Lens.org** | 401 ⚠️ | **нужен** | Хорошая связка «патент ↔ публикация», но академический доступ по заявке |
| **Роспатент API** | нет соединения ❌ | — | С этого сервера недоступен |
| **ФИПС** | 403 ❌ | — | Блокирует автоматические запросы |

**Решение 09.09.2026: отказываемся от всех источников, требующих ключа.**

Причина практическая: ключи выдаются под академическую или корпоративную почту
и организацию, которых у команды нет; часть сервисов недоступна из России.
Проверка показала, что бесключевого обхода у патентных API не осталось: старый
`api.patentsview.org` редиректит на ключевой `search.patentsview.org`, а
PatentsView переехал на `data.uspto.gov`, чей API отвечает `Unauthorized`.

Что теряем и чем заменяем — в §4.

## 3. Ранние («серые») сигналы

Самые ранние индикаторы — там, где нет рецензирования:

| Источник | Статус | Что даёт |
|---|---|---|
| **HuggingFace API** | 200 ✅ | Модели и датасеты с датами. Новая архитектура появляется здесь раньше, чем в журналах |
| **GitHub API** | 200 ✅ | Динамика звёзд/форков по теме. 60 запросов/час без токена, 5000 с токеном |
| Papers with Code | — | Связка «статья ↔ код ↔ бенчмарк» |
| Hacker News / Habr | 301 | Habr — русскоязычный индустриальный сигнал |
| Отчёты (Gartner, McKinsey, CB Insights) | — | PDF, парсинг оффлайн. Заказчик прямо упомянул «аналитические отчёты» |

## 4. Чем заменяем источники под ключом

Проверено живыми запросами 09.09.2026.

| Что давал бы ключ | Чем заменяем | Проверено |
|---|---|---|
| Semantic Scholar: `tldr`, граф цитирований | `cited_by_count` из OpenAlex; выжимку пишет наша же RAG-генерация по абстрактам | ✅ |
| CORE: полные тексты | Не нужны: скоринг и карточки работают на заголовках и аннотациях | — |
| PatentsView / EPO: патенты как сигнал коммерциализации | Корпоративные аффилиации в OpenAlex + активность на GitHub и HuggingFace | ✅ |

**Корпоративные аффилиации — ключевая замена.** OpenAlex размечает тип
организации, и фильтр `authorships.institutions.type:company` даёт 8,9 млн работ.
Запрос по теме сразу отвечает на вопрос заказчика «какая компания ведёт разработку»:

```
filter=concepts.id:C154945302,
       title_and_abstract.search:"state space model",
       publication_year:2024-2026,
       authorships.institutions.type:company
group_by=authorships.institutions.lineage
```

Ответ: Google, Google DeepMind, Alphabet, Chinese Academy of Sciences. То есть
**поле «кейс-пример» из ТЗ закрывается без патентов вообще.**

**Что при этом теряем честно.** Метрику T — лаг «публикация → патент» как
признак коммерциализации. Это была наша добавка сверх ТЗ, а не требование
заказчика. В архитектуре остаётся разъём под патентный коннектор: в контуре
банка, где корпоративные учётные записи есть, он подключается конфигом.

## 5. Русскоязычные источники

Отдельный риск: eLIBRARY даёт 302 (редирект/бот-защита), ФИПС — 403, Роспатент
недоступен. Прямого API нет ни у одного.

Варианты: доступ с российского IP, ручная выгрузка датасета заранее, либо
опора на международные базы с фильтром по российским аффилиациям (в OpenAlex
это `authorships.institutions.country_code:RU`). Последнее работает уже сейчас и
не требует ничего дополнительного — **берём как основной путь**.

## 6. Что это значит для архитектуры

Источники разделяются по **лагу сигнала** — и это ложится в скоринг:

```
опережающие          подтверждающие        запаздывающие
(зарождение)         (валидация)           (коммерциализация)
─────────────────────────────────────────────────────────────►
GitHub, HuggingFace  arXiv, bioRxiv        журналы, патенты
блоги, гранты        конференции           отчёты, стандарты
```

Тренд, который виден только в запаздывающих источниках, уже не зарождающийся.
Тренд, который виден только в опережающих, — гипотеза с высокой неопределённостью.
Пересечение — то, что нужно заказчику.

## 7. Лимиты и вежливость

- OpenAlex: без ключа ~10 запросов/сек, обязательно указывать `mailto` (polite pool).
  В ответе приходит поле `cost_usd` — расход считается, но бесплатный лимит щедрый.
- Все ответы кэшируются на диск (`data/cache/`), повторные прогоны бесплатны.
  Это же даёт **оффлайн-режим для демо** — критично, если на защите не будет сети.
