### Костя: живой сбор по произвольному запросу

**Это единственное, что отделяет нас от выполнения ТЗ.** Жюри введёт
направление, которого нет в индексе, и будет ждать результат.

| Задача | Критерий готовности |
|---|---|
| K-10 справочник доверенности | у каждого домена из датасета есть `trust_level` |
| K-11 новостные коннекторы | RSS, Hacker News, Google News — без ключей |
| K-12 **живой сбор** | запрос → ≥300 документов за ≤3 минуты, `data/live/{slug}/` по контрактам |
| K-13 кандидаты из живого корпуса | термины + имена компаний, техно-фильтр обязателен |

Заполнять обязательно: `date`, `url`, `trust_level`, `source_type`.
Без них живой скоринг считать не по чему, а карточка источника пуста.

**Что снято окончательно:** кластеризация полного корпуса, докачка новых
доменов, эмбеддинги. Времени нет, и в сдачу они не входят.

**Замер, который стоит знать.** Полный корпус из 6,3 млн работ дал ТОП-15 из
обрывков заголовков: `algorithms for fault`, `children using machine learning`.
Эталонные технологии — ниже 3000-го места. Разбор: `validation/FULL_CORPUS_FINDINGS.md`.
N-граммы из заголовков на таком объёме не работают — нужны имена технологий
и компаний из новостей. Это и есть K-13.
