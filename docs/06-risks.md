# Риски и как их снимаем

Отсортировано по ожидаемому ущербу.

| # | Риск | Вероятность | Ущерб | Что делаем |
|---|---|---|---|---|
| 1 | **Демо падает на защите** (нет сети, тормозит источник, кончилась квота) | Высокая | Критический | Полный оффлайн-режим: предрассчитанный индекс + кэш ответов в репозитории. Демо обязано работать в самолётном режиме. Плюс записанное видео как запасной вариант |
| 2 | **Выдаём мейнстрим вместо слабых сигналов** | Высокая | Критический | Уже воспроизвели на спайке. Лечение — генерация кандидатов из длинного хвоста, опережающие источники, жёсткий штраф за зрелость (см. методологию §4) |
| 3 | **Жюри спрашивает «а почему это тренд?» и ответа нет** | Средняя | Критический | Каждое число кликабельно до первоисточника. Вкладка «Методология» прямо в интерфейсе. Режим `as_of` для живого бэктеста |
| 4 | **ТЗ окажется существенно шире открытой формулировки** | Средняя | Высокий | Готовим переиспользуемые кирпичи (коннекторы, метрики, API-каркас), а не готовый продукт под угаданное ТЗ. Первый день после открытия ТЗ — только на разбор и перепланирование |
| 5 | **Артефакты данных попадают в ТОП** | Высокая | Высокий | Структурные фильтры уже написаны и проверены (поймали пакетную заливку `lynching tree`). Расширять по мере находок |
| 6 | **Галлюцинации LLM в мотивации и кейсах** | Средняя | Высокий | Только RAG по найденным документам, строгая JSON-схема, отбрасывание утверждений без `doc_id`, метрика покрытия источниками |
| 7 | **Не успеваем за 2 недели** | Средняя | Высокий | Жёсткий MVP-контур на первую неделю: один домен, один источник, сквозной путь до экрана. Дальше — расширение вширь |
| 8 | ~~Ключи к патентным API не успевают прийти~~ **Снято 09.09.** Ключи не берём вообще: выдаются под организацию, которой у команды нет | — | — | Сигнал коммерциализации собираем из корпоративных аффилиаций OpenAlex (8,9 млн работ, фильтр `institutions.type:company`) плюс GitHub и HuggingFace. Поле «кейс-пример» из ТЗ закрывается без патентов |
| 9 | **Русскоязычные источники недоступны** (eLIBRARY 302, ФИПС 403, Роспатент недоступен) | Высокая | Средний | Основной путь — фильтр по российским аффилиациям в международных базах. Работает уже сейчас |
| 10 | **Омонимия ломает год взлёта** | Высокая | Средний | Измерено: «diffusion model» → 2005 (физика). Разрешение смысла по эмбеддингу контекста + привязка к теме, а не к строке |
| 11 | **Расхождение с ожиданиями заказчика по формату выдачи** | Средняя | Средний | Вопросы организаторам в первый же день (см. 08-open-questions.md) |
| 12 | **Один сильный разработчик — узкое место** | Средняя | Средний | Разделение по слоям: данные / ML / API+фронт. Общий контракт API фиксируем в первый день |
