# K-13: устранение ложных имён из заголовков — 24 сентября 2026

Причина: после обнаружения капитализированного слова в контексте действия
или притяжательной конструкции генератор пересчитывает все его упоминания
без учёта регистра. Обычное слово из Operator's Guide, Model's Behavior или
AGent становится гипотезой имени и набирает порог на несвязанных заголовках.

Решение: расширить явный отсев общеупотребительных слов до пересчёта сущностей.
Не отключать техно-фильтр, не снижать min_docs=3, не изменять научные корпуса.
Полные названия с отличительным компонентом (Acme Network, Guidewire,
Applied Computing) сохраняются. Технологические словосочетания по независимым
правилам, например neuromorphic computing, также сохраняются.
Известные персона/география/международная группа не являются компаниями.
Это конечные английские правила, а не утверждение о полноценном NER.

- [x] Регрессии: фактические Guide-заголовки, обычные слова/служебные части речи,
  сохранение различимых составных имён и настоящих технических терминов.
- [x] Исправить semantic/live.py; указать новую версию метода в meta.
- [x] Пересчитать только небольшие live-индексы и FEATURES офлайн в новые каталоги.
- [x] Проверить удалённые кандидаты, сохранённые имена, схемы/SHA/связность;
  сравнить на прежних и исправленных входах, не смешивая эффект данных и кода.
- [x] Ревью, тесты ingest/semantic, актуальные пакеты и единый статус K-10–K-15.

Никаких новых зависимостей, сети, Git-изменений, скоринга или чужого кода.
Автономное выполнение разрешено пользователем; завершённые полные корпуса
не пересобираются. Готовность механизма не равна оценке новизны/Precision/Recall.
