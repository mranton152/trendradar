# K-03–K-08: исполнение брифа Константина

План согласован задачей пользователя «Сделай остальные задачи» и «Продолжай».
Область изменений: ingest/, semantic/ и предусмотренные выходные данные.
Контракты и золотой снапшот сохраняются. Полный корпус не подменяется выборкой.

- [ ] ingest/full.py: годовая cursor-пагинация без sample, атомарные страницы,
  checkpoint, конфигурация возобновления и статус incomplete до завершения.
- [ ] semantic/embed.py: e5-large passage-префикс, 512 токенов, CUDA, снижение
  batch при OOM, memmap float32, документный порядок и хэш корпуса, checkpoint.
- [ ] semantic/cluster.py: UMAP/HDBSCAN по брифу, seed42, сравнение10/25/50,
  настоящая формула c-TF-IDF, шум исключён, нормированные центроиды кандидатов.
- [ ] semantic/terms.py и filter.py: документная частота n-грамм, порог20,
  технологические маркеры и исключения с объяснениями. Лексическая эвристика
  не выдаётся за полноценную POS-модель.
- [ ] semantic/build.py: термины и кластеры в общих контрактных таблицах;
  embeddings.npy содержит кандидатов, документные embeddings отдельно;
  проверка ссылок doc_id/emb_row/n_docs и manifest с охватом корпуса.
- [ ] Реальные проверочные прогоны AI/quantum-computing/biotechnology,
  корректные meta.json и отдельные директории smoke (не полный индекс).
- [ ] Тесты с независимыми ожиданиями; контрактная валидация, код-ревью,
  фиксация доступных результатов и фактических блокировок тяжёлых прогонов.

Зависимости уже входят в pyproject.toml[ml]; устанавливаются в рабочее venv.
GPU: RTX3070Laptop 8ГБ; свободно около175ГБ диска на начало работы.
LM Studio не заменяет фиксированный алгоритм UMAP/HDBSCAN; для e5 используется
предусмотренный проектом sentence-transformers на GPU. API-ключи не выводятся.

Реализация идёт независимыми задачами: агент ingest, агент terms/filter,
основной агент embed/cluster/build. Общие файлы не редактируются параллельно.
