# K-14: признаки из наблюдённого новостного корпуса

Реализовано по опубликованному `contracts/schemas.py::FEATURES`.
Никаких сетевых запросов, вызовов LLM или изменений классификатора.

```powershell
python -m ingest.features --index PATH_TO_LIVE_INDEX --as-of 2026-09 --output NEW_OUTPUT_DIR
```

Вход: live-индекс с works.parquet, candidates.parquet, cand_docs.parquet и meta.json.
Выход: features.parquet по FEATURES и meta.json с SHA входов/выхода, покрытием
источников, числом null и ограничениями. Существующий результат не перезаписывается.
До записи проверяются SHA/count, уникальность ID/связей, внешние ключи и n_docs.
CLI ограничена 200 тысячами документов/кандидатов и 2 млн связей; полный корпус
6,3 млн работ не является её входом. Результат публикуется атомарно каталогом.

Функция для интеграции:

```python
from ingest.features import news_features
values = news_features(cand_docs_rows, works_rows, as_of="2026-09")
```

Оба входа — последовательности словарей, например Arrow Table.to_pylist().
Возвращается dict[cand_id, dict] по кандидатам с документами. CLI добавляет
обязательные cand_id/label/domain/as_of и сохраняет остальных кандидатов с null.

## Смысл полей

- news_mentions_by_month: ровно 24 календарных месяца, старые первыми,
  включая весь as_of. Для 2026-09 окно начинается 2024-10-01 и заканчивается
  перед 2026-10-01. Это число различных связанных документов, не число слов.
- news_mentions_24m: сумма ряда; repo/model/научные статьи не считаются новостями.
- news_first_month: самое раннее наблюдённое упоминание до конца as_of,
  включая более старые месяцы, не «дата появления технологии».
- funding_mentions: документы со словами funding/raises/raised/series/seed/
  stealth/pilot/launch(es/ed). Один документ учитывается один раз; название
  издателя Google News исключается. Это лексический признак, не проверка сделки.
- n_domains: уникальные нормализованные хосты первичных URL в окне. Если хотя бы
  один первоисточник скрыт агрегатором, поле null, а не неполный счётчик сайтов.
- trusted_share: доля таких хостов с однозначным trusted. Unknown, отсутствующий
  первоисточник или отсутствие новостей дают null; смешанные оценки одного хоста
  трактуются консервативно. Число документов не служит знаменателем этой доли.
- langs: наблюдённые непустые языки новостей в окне.
- n_companies: null по умолчанию. Функция принимает необязательный
  company_mentions={doc_id: [company_name, ...]} — полную внешнюю разметку каждого
  документа окна. При неполной разметке остаётся null. K-13 смешивает гипотезы
  компаний и продуктов, поэтому автоматически не используется как эта разметка.

Если у связанной новости нет даты, все новостные признаки кандидата становятся
null: нельзя утверждать, что она вне окна. Некорректная дата — ошибка.
Будущие документы исключаются. Дубли связей функция схлопывает; CLI отвергает
некорректный индекс с дублями. Неизвестный doc_id всегда ошибка.

Остальные поля FEATURES (публикации, GitHub/HF, обучающие метки) остаются null:
эта стадия не подменяет сборщик Антона. Нули означают отсутствие в наблюдённом
корпусе, а не во всём интернете. Статусы частичного сбора сохранены в meta.json.

## Необязательная разметка издателей — 24 сентября 2026

`--source-evidence PATH.json` принимает заранее проверенную внешнюю разметку.
Для интеграции функции: `publisher_urls={doc_id: original_url}`. Без параметра
поведение прежнее. Уровень доверенности исходного хоста берётся из ingest.trust;
WORKS и его даты остаются неизменными.

JSON содержит format=`reviewed-publisher-links-v1`, corpus_sha256 (works.parquet),
cand_docs_sha256 и список documents. Каждая запись содержит doc_id, aggregator_url
(точный URL из WORKS), original_url, verification=`publisher_title_match` и
page_sha256 (64 шестнадцатеричных символа SHA256 проверенного HTML).

Файл готовит проверяющий: доступный HTML, соответствующий статье заголовок,
сохранённый SHA. Разрешённая ссылка из origins сама по себе недостаточна.
CLI проверяет формат, SHA индекса, уникальность ID, исходный URL, метку проверки,
форму SHA HTML и допустимость адреса. Сам HTML CLI не читает: его SHA — ссылка
на внешнее доказательство, не удостоверение подлинности. Служебные Google URL,
локальные адреса и известные агрегаторы отвергаются. Вторичные агрегаторы,
ещё не внесённые в справочник, обязан исключить проверяющий. Переопределить
прямую ссылку документа этим параметром нельзя.

В meta.json записываются SHA разметки и правил доверенности, число исходных URL.
Частичное покрытие кандидата не превращается в полный n_domains; неизвестный
уровень любого хоста оставляет trusted_share=null. Даты HTML не заменяют даты
агрегатора; хосты не равны независимым редакциям.

Результат: 28 проверенных ссылок, 13 строк FEATURES. Из 30 совпавших заголовков
исключены BigGo Finance и NewsCord как вторичные агрегаторы. Только n_domains
Apple (1) и Gemini (4) перешли из null в число. Остальные поля совпали с прежним
файлом, включая trusted_share. Актуальный каталог workspace:
`outputs/phase1/acceptance-20260923/features-publishers-20260924-checked/`.
Разметка: `publisher-audit-20260924/reviewed-publishers-checked.json` рядом.
188 тестов ingest/semantic пройдены; ruff и отдельный валидатор FEATURES прошли.
Интеграция с классификатором остаётся отдельной задачей владельца.
