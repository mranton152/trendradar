# Доверенность источников — K-10

`classify(url_or_domain)` возвращает trust_level, source_type, rule_domain и reason.
Правила из брифа дополнены source_trust.json с основаниями и ссылками.
Неизвестный домен получает unknown; тип None, если его нельзя подтвердить.
Реестр — доменная оценка, а не проверка достоверности каждой статьи.
Пресс-релиз внутри доверенного домена требует отдельной маркировки коннектором.
Google News и Hacker News остаются агрегаторами: доверенность издателя можно
использовать только при установленной ссылке на оригинальный материал.

## Датасет

Из исходного xlsx извлечены 100 строк технологий, 285 ссылок и 206 уникальных
хостов (без www). dataset_sources.json содержит ссылки и SHA-256 оригинала,
но не копию датасета и не локальный пользовательский путь.
Для каждого домена есть явная запись source_trust.json. Покрытие206/206
не означает, что все источники заслуживают доверия. Проверка первичных сайтов
проведена 2026-09-19; недоступность или неоднозначное описание оставляют unknown.
reviewed_first_party означает классификацию по описанию владельца сайта,
а не независимый аудит качества его материалов. unresolved_access и
unresolved_identity требуют дополнительных сведений перед повышением доверенности.

Текущие количества: {"unknown": 79, "indicator": 21, "trusted": 106}.
Основание, ссылка и дата проверки сохранены в реестре. Для организаций со
смешанными публикациями source_type остаётся None: тип документа определяет
коннектор. Рекламные материалы и пресс-релизы нельзя автоматически повышать
до trusted только потому, что их выпустил разработчик.

## Проверки

Тесты проверяют покрытие датасета, spoofing доменов, IDN, поддомены,
некорректные URL, индикаторы пресс-релизов. Подстановки по ключевым словам
в названии домена не используются. Исходный Excel не менялся.
