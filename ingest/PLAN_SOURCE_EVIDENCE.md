# Подтверждённые исходные ссылки для K-14

Цель: необязательное офлайн-дополнение FEATURES без переписывания WORKS.
Пользователь разрешил автономное выполнение; Git и чужие каталоги не меняем.

Выбран отдельный файл доказательств вместо замены URL корпуса или автоматического
принятия всех разрешённых ссылок. Последние два варианта теряют происхождение
либо принимают непроверенные страницы за издателей. Даты остаются наблюдёнными
датами WORKS, события и число упоминаний не меняются.

- [x] Тесты API: подтверждённые хосты, неизвестная доверенность, неполное покрытие,
  отсутствие мутаций; неправильные doc_id и служебные URL отвергаются.
- [x] news_features(..., publisher_urls=None): необязательная карта doc_id → URL;
  уровень доверенности исходной ссылки только из ingest.trust.classify.
- [x] CLI --source-evidence: отдельный JSON формата reviewed-publisher-links-v1,
  SHA works/cand_docs, уникальные doc_id, точное совпадение aggregator_url,
  original_url и отметка publisher_title_match с SHA HTML. Ошибка до записи output.
  Это переданная проверяющим разметка, а не самостоятельное удостоверение истины.
- [x] Подготовить файл из сохранённого аудита, исключив несовпадения заголовков,
  недоступные страницы и явно вторичные агрегаторы; сохранить SHA аудит-артефактов.
- [x] Пересчитать в новом каталоге. Проверить FEATURES, неизменность временных
  рядов, событий, WORKS и старых результатов; проверить новые домены вручную.
- [x] Обновить README/STATUS, выполнить целевые тесты и ruff; ревью изменений.

Неизвестные/неразрешённые источники сохраняют null. Внешняя разметка не должна
переопределять прямые ссылки. Считаются уникальные хосты, не редакции или владельцы.
Никаких новых сетевых запросов, зависимостей, обучения или скоринга.
