# Новостные коннекторы K-11

Общий `NewsClient(http, cache, deadline=...)` принимает httpx.AsyncClient и
абсолютное время time.monotonic(). Успешные ответы кэшируются на час, запись
атомарна. Повторяются 429, 500/502/503/504 и транспортные ошибки, до трёх попыток.
Retry-After учитывается, общий deadline прерывает ожидание. Ключи не требуются.

Новая зависимость по брифу: `feedparser>=6.0,<7` (проверено с 6.0.14).
Установлена в рабочее venv. Перед передачей необходимо добавить её в общий
pyproject.toml через владельца; этот файл в данной ветке не изменялся.

Коннекторы sources/{rss,gnews,hackernews,github,huggingface}.py возвращают WORKS.
RSS получает последние публикации всей ленты: фильтрация по запросу нужна в K-12.
Google News с URL-оболочкой остаётся indicator/aggregator, даже если source
называет Nature. Разрешение ссылки в оригинал пока не реализовано.
Hacker News отдаёт ссылку на обсуждение и indicator/aggregator; внешний URL и
очки остаются в сыром кэше. GitHub stars и HF likes также остаются в кэше;
cited_by=null, потому что эти метрики не являются цитированиями.
Записи без даты создания/публикации пропускаются, дата обновления не подставляется.

Реальная проверка 2026-09-19: TechCrunch 20, SiliconANGLE 30, The Register 50,
EE Times 10, HN 300, Google News 101, GitHub 100, HF 100. VentureBeat: HTTP429
после повторов. Все восемь parquet прошли контракт WORKS. Это проверка доступа
и схем, не измерение релевантности или критерия K-12 на машине жюри.

Общие проверки: 259 passed, ruff check . без ошибок.
