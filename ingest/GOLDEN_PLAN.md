# Золотой снапшот: K-01 / K-02

Цель: настоящий срез OpenAlex по Artificial intelligence (C154945302),
2015–2026, 5000 уникальных работ, контракт WORKS, менее 50 МБ.

Архитектура: HTTP с атомарным дисковым кэшем и повторами → нормализация
OpenAlex → выборка по годам (seed=42, одинаковый размер страниц) → Parquet.
На 2015–2022 приходится по 417 работ, на 2023–2026 — по 416.
В каждом году запрашивается запас 100 записей; документы без обязательных
данных исключаются с причинами в manifest. Дата --as-of обязательна.
Это равномерная по годам тестовая выборка, не оценка частот полного корпуса.
2026 ограничен датой сбора. Повтор использует кэш; seed сам по себе не
фиксирует меняющуюся базу OpenAlex. Исходные ответы сохраняются локально.
