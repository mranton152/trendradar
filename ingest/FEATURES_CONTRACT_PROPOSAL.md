# K-14: предложение для согласования Антоном, не утверждённый контракт

Бриф требует согласовать формат до реализации. Код features.py пока не написан.

Предлагаем `news_features(cand_docs, works, *, as_of) -> dict[cand_id, dict]`:
явный as_of нужен для воспроизводимого окна 24 календарных месяца.
Если обязательна сигнатура ровно с двумя аргументами, нужно определить источник as_of.

Для каждого cand_id:
- monthly_mentions: 24 пары month YYYY-MM и n_docs, включая нулевые месяцы;
- n_domains: разные нормализованные хосты оригинальных URL в окне;
- n_trusted_sources: разные хосты документов с trust_level=trusted в окне;
- n_companies: число уникальных подтверждённых компаний, не всех слов с заглавной буквы;
- event_mentions: funding/raises/series/seed/stealth/pilot → число разных документов,
  содержащих слово в заголовке, с границами слова и без учёта регистра;
- n_undated: число связей, исключённых из окна из-за отсутствующей даты.

Каждая пара cand_id/doc_id учитывается один раз. Неизвестные doc_id — ошибка.
WORKS не содержит структурированных компаний; для n_companies требуется решить,
откуда брать подтверждённые сущности, либо согласовать явно эвристическую оценку.
Google News/HN не увеличивают число независимых оригинальных издателей до
разрешения оригинального URL. Число источников и документов не смешиваем.
