# Исходные ссылки агрегаторов

`python -m ingest.origins --index LIVE_INDEX --raw-cache INGEST_CACHE --cache RESOLVE_CACHE --output NEW_DIR --budget 120`

Этап обрабатывает только документы Google News/Hacker News, связанные с кандидатами.
Он не меняет WORKS, FEATURES, trust_level и doc_id. Результат — origins.json:
doc_id, aggregator_url, original_url, method, status, article_fetched=false.
SHA корпуса и связей привязывают артефакт к конкретному индексу.

Hacker News: точное соответствие URL обсуждения и заголовка записи в кэше Algolia.
Используется явный outbound URL; неоднозначные варианты не принимаются.
Google News: параметры страницы перехода и её ответ garturlres. Формат сверялся
с [описанием открытого проекта GoogleNewsDecoder](https://github.com/dbernheisel/google_news_decoder/blob/main/README.md)
и [примером протокола](https://gist.github.com/huksley/bc3cb046157a99cd9d1517b32f91a99e?permalink_comment_id=5173507).
Сторонняя библиотека не устанавливалась. Это внутренний, нестабильный интерфейс Google.

Запросы идут только к Google, статьи издателей не скачиваются. HTTP-редирект
сохраняется как ссылка без перехода по нему. Google sorry/consent/accounts/search
не принимаются за статью. После ошибки новые сетевые запросы Google в этом
запуске останавливаются; уже доступный кэш продолжает использоваться.
Параллелизм — три, общий дедлайн, ограничение ответа и ретраи транспорта.
CAPTCHA и ограничения не обходятся. Для повторения без сети есть `--offline`.
GET и POST имеют разные ключи кэша; режим запрета редиректов тоже отделён.

Разрешённая ссылка — не проверка доступности статьи, её содержания, даты,
авторства или независимости от других публикаций. Среди целей могут быть
научные статьи и вторичные агрегаторы. Автоматического повышения trust нет.
Следующий этап — проверка страниц и использование доказанного происхождения
при подсчёте источников; FEATURES пока не переписан.

## Фактический результат 23 сентября 2026

Исходный успешный прогон: 51 ссылка (36 Google News, 15 Hacker News), 4,828 секунды.
Это связанные документы текущих 13 кандидатов, не все 793 документа корпуса.
Действующий артефакт в workspace:
`outputs/phase1/acceptance-20260923/origins-verified-offline/origins.json`.
Офлайн-проверка подтвердила ранее полученные адреса; исходный WORKS не изменён.

При повторном сетевом прогоне Google вернул 36 служебных перенаправлений /sorry.
Первичная проверка ошибочно посчитала их исходными адресами. Ошибка исправлена
регрессионным тестом. Каталоги origins-checked и origins-checked-offline
недействительны; их нельзя использовать. origins-blocked-audit фиксирует
36 BlockedOrigin и 15 доступных ссылок HN. Новых запросов после обнаружения
ограничения не делалось. Действующий результат взят из первого успешного кэша,
а не из ограничивающих ответов Google. Нельзя считать такой интерфейс надёжным
для демонстрации без кэша; при отказе остаётся URL агрегатора и явный статус.
