# Live-сбор и датасет: K-12, K-13, K-15

## Запуск

Из корня репозитория:

```powershell
$env:LLM_BACKEND = 'lmstudio'
$env:LLM_BASE_URL = 'http://localhost:1234'
$env:LLM_MODEL = 'trendradar-translator'
python -m ingest.live --query 'кибербезопасность' --budget 180
```

LM Studio требует JSON Schema, поэтому ingest.translate_worker использует
адаптер-наследник cards.llm.LLM. Для других провайдеров работают прежние
LLM_BACKEND=ollama/openai_compatible. Модель, промпт и ответ попадают в meta.json.
Фразы проверяются на ASCII/латиницу; это защита от непереведённого русского текста,
не автоматическая оценка смысловой точности перевода.

Общий бюджет ограничивает перевод и сеть; сохранение parquet добавляет небольшие
затраты после сетевого deadline. При ошибке источника статус partial, готовые
страницы сохраняются. Ошибки/таймауты отражаются по каждому запросу источника.
Перевод выполняется в отдельном процессе, который завершается при таймауте.
Точечная история OpenAlex требует OPENALEX_API_KEY; без него явно пропускается.
Для истории резервируется до 30 секунд. Полные научные корпуса не пересобираются.

При одинаковом URL/заголовке приоритет у доверенного оригинала. Google News
с неразрешённой ссылкой остаётся агрегатором; полнота независимых источников
от этого ограничена. RSS фильтруется по словам перевода; релевантность требует
оценки на данных, большой n_docs сам по себе не доказывает качество.

## Live-индекс

```powershell
python -m semantic.build --scope live --domain DOMAIN_FROM_META --works PATH/works.parquet --output NEW_INDEX --cache data/live-semantic-cache --as-of 2026
```

Live принудительно отключает эмбеддинги/кластеры и задаёт min_docs=3.
Сущности распознаются эвристически по капитализации в технологическом контексте;
они не считаются подтверждёнными юридическими лицами. Схему kind не расширяем:
сущности используют kind=term, список их ID записывается в метаданные.
Индекс проверяет SHA256/число строк/домен source meta и сохраняет журнал сбора.

## Датасет

`python -m ingest.dataset --xlsx PATH --output data/dataset --cache data/dataset-cache`
обрабатывает ровно 100 строк первого листа (номер B, технология C).
Сохраняются SHA256 xlsx, запросы и журналы перевода. Готовые результаты не
перезапускаются; неоднозначный незавершённый каталог требует проверки.
Ошибки источников не превращаются в подтверждение полноты корпуса.

Для текущего прогона сырой вывод находится в workspace/outputs/phase1/dataset,
проверенный offline replay — в C:/projects/trendradar/data/dataset.
validation.json содержит фактические количества и SHA256 каждого корпуса.
