# K-03: полный корпус OpenAlex

`python -m ingest.full` обходит все страницы каждого года, без `sample`.
Фильтр: точный OpenAlex concept по slug домена, `article|preprint|report`,
год публикации и обязательная верхняя дата `--as-of`.
Если имя OpenAlex отличается от slug, передайте `--concept-id C58053490`:
ID проверяется через API, имя концепта сохраняется в manifest; для этого примера
домен `quantum-computing` соответствует концепту `Quantum computer`.

Ограниченная проверка (не запускайте без оценки квоты OpenAlex):

```powershell
python -m ingest.full --domain artificial-intelligence --years 2015-2026 --as-of 2026-09-09 --max-pages 1
```

Повтор той же команды продолжает с сохранённого курсора. `--max-pages` ограничивает
число страниц works за текущий запуск; поиск concept при первом запуске — ещё один
запрос. HTTP-ретраи могут добавить запросы. Без `--max-pages` команда скачивает
весь оставшийся корпус; такой запуск требует предварительной оценки квоты и диска.
API-ключ берётся существующим HTTP-клиентом из `OPENALEX_API_KEY`.

Результат: `data/corpus/{domain}/works.parquet`, контракт `WORKS`. Можно задать
`--output` и `--cache`; `--offline` разрешает только сохранённые HTTP-ответы.
Золотой snapshot CLI `ingest.harvest` не изменён.

До конца обхода `manifest.json` содержит `status: incomplete`, текущий год,
курсор и счётчики; `works.parquet` не публикуется. Каждая страница сначала
атомарно сохраняется в `pages/000000000.parquet`, затем коммитится курсор.
Сбой между этими действиями приводит к безопасному повтору той же страницы.
Отброшенные записи и причины хранятся в соседних `*.rejected.json`.
Не меняйте и не удаляйте страницы завершённого или продолжаемого прогона.
Одновременные процессы в одном `--output` не поддерживаются.

При завершении DuckDB дедуплицирует по `doc_id`, выбирая первую страницу,
сортирует по году/id и отдаёт батчи PyArrow. Лимит RAM DuckDB — 512 MiB;
промежуточные данные сбрасываются в `duckdb-tmp`. Полный корпус не загружается
в Python-список. Нужен свободный диск для страниц, кэша и финальной сортировки.
Финальный manifest содержит число уникальных документов, дубликатов, отбраковок,
счётчики по годам и SHA-256. DuckDB уже предусмотрен стеком проекта.

Домен, годы, дата и размер страницы фиксируются в конфигурации прогона.
Изменение требует отдельного каталога. `--as-of` ограничивает дату публикации,
но не замораживает изменяемую базу OpenAlex; сохраняйте HTTP-кэш для повторяемости.
Год даты среза неполный. Полнота означает завершение обхода выбранного фильтра,
а не покрытие всех научных источников; невалидные записи явно учитываются.

Проверка без сети:

```powershell
python -m pytest ingest/test_full.py -q
python contracts/validate.py data/corpus/artificial-intelligence/works.parquet --schema works
```
