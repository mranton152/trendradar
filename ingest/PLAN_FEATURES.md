# K-14: новостные признаки по действующему FEATURES

Цель: офлайн-функция news_features(cand_docs, works, *, as_of) и CLI
python -m ingest.features --index DIR --as-of YYYY-MM --output DIR.
Контракт уже опубликован владельцем в contracts/schemas.py; чужие файлы не меняем.
Новые зависимости не нужны: Python, Arrow, Parquet.

- [x] Тесты границ окна, повторов связей, неизвестных ID, агрегаторов и пропусков.
- [x] Функция считает только наблюдённые новости (rss/gnews/hackernews либо news/blog/
  press_release/aggregator), отдельно от репозиториев и научных статей.
- [x] 24 календарных месяца включительно с as_of; первое упоминание — самое раннее
  наблюдённое до конца as_of, включая старые месяцы. Будущие документы исключаются.
- [x] n_domains/trusted_share — по уникальным известным хостам прямых новостей;
  aggregator не означает первоисточник. Если оригиналы не разрешены, значения null:
  иначе неполное покрытие выглядело бы как полный подсчёт сайтов.
- [x] n_companies null без явно переданной полной разметки компаний по документам.
  Имена K-13 включают продукты и гипотезы, не использовать их как подтверждённые компании.
- [x] CLI проверяет SHA/count исходного индекса, внешние ключи и n_docs; атомарно
  пишет FEATURES и метаданные с определениями/пропусками/покрытием.
- [x] Проверить на текущем индексе 793 документов/13 кандидатов, схемы и 24 месяца,
  тесты и независимое ревью; записать фактический статус.

trusted_share — доля уникальных исходных хостов с trusted; неизвестный уровень
даёт null, смешанные оценки одного хоста разрешаются консервативно (не trusted).
funding_mentions — число разных документов с funding/raises/raised/series/seed/
stealth/pilot/launch(es/ed), границы слов, без учёта регистра. Это лексический
индикатор события, не доказательство сделки. Нет даты — временные признаки null.
Ряды описывают собранный корпус, не число всех публикаций в интернете.
