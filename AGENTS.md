# TrendRadar — брифинг для ИИ-ассистента

Этот файл читают Claude Code, Codex и ChatGPT в начале работы. Он объясняет,
что за проект, где чьи границы и чего делать нельзя.

## Что за проект

Сервис детекции **зарождающихся** научно-технологических трендов (слабых сигналов)
для Платформы ИИ-аналитики Газпромбанка. Хакатон ЛЦТ-2026.

Ввод: технологическое направление свободным текстом («технологии в ИИ»).
Выход: ТОП-15 трендов, у каждого — мотивация, кейс-пример, ссылка на первоисточник
и доказательство того, что тренд именно зарождающийся (год взлёта, динамика публикаций).

**Побеждает не «LLM придумала 15 трендов», а измеримый и воспроизводимый детектор
с доказательствами.** Числа считает статистика по корпусу, LLM только формулирует
текст по найденным документам и не имеет права утверждать ничего без `doc_id`.

Подробности: `README.md`, `docs/00-task-analysis.md`, `docs/01-methodology.md`.

## Архитектурный принцип

Система — это **набор CLI-стадий, которые пишут parquet-файлы**, плюс read-only API
поверх этих файлов. Никакого сервера БД, никакой очереди задач.

```
ingest/    → data/corpus/{domain}/works.parquet
semantic/  → data/index/{domain}/{candidates,cand_docs}.parquet + embeddings.npy
core/      → data/index/{domain}/trends.parquet
cards/     → data/index/{domain}/cards.parquet
api/ web/  → читают data/index/, ничего не считают
```

Следствия, которые нельзя ломать:
- любая стадия запускается отдельно и воспроизводима;
- демо работает **без сети** — индекс это файлы;
- схемы колонок описаны в `contracts/schemas.py` и являются законом.

## Правила, обязательные для ассистента

1. **Пиши только в папки своего владельца.** Заметил проблему в чужой папке —
   опиши её в тексте ответа, не правь файл.
2. **Не меняй `contracts/schemas.py`.** Если задача требует нового поля —
   останови работу и скажи об этом вслух.
3. **Не рефакторь то, что не просили.** Особенно чужой код и общие файлы.
4. **Не добавляй зависимости молча.** Новая библиотека — отдельным пунктом в ответе,
   с обоснованием и записью в `pyproject.toml`.
5. **Никакой генерации содержания трендов «из головы» модели.** Любой текст в карточке
   выводится из документов корпуса и несёт `doc_id`. Утверждение без источника
   выбрасывается.
6. **Стек фиксирован** (см. ниже). Хочешь другой — сначала спроси.
7. Комментарии и документация — по-русски, идентификаторы в коде — по-английски.

## Стек (зафиксирован, не менять без обсуждения)

Python 3.12 · pyarrow + DuckDB + Parquet · numpy/scipy · sentence-transformers
(`intfloat/multilingual-e5-large`) · UMAP + HDBSCAN · FastAPI + Pydantic v2 ·
Next.js 15 + TypeScript + Tailwind + Recharts · Ollama (абстракция провайдера) ·
uv для зависимостей · ruff + pytest.

Сознательно **не используем**: Postgres, Redis, Celery/arq, Kafka, Airflow,
Kubernetes, отдельную векторную БД. На две недели это накладные расходы.
